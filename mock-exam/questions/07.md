# Question 07: Department Location List

**Topic Covered**: `SELECT`

## Database Schema Reference

### Table: `departments`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `department_id` | `INT` | PRIMARY KEY | Unique identifier for department |
| `department_name` | `VARCHAR(50)` | NOT NULL | Department name (e.g. Sales, Engineering) |
| `location` | `VARCHAR(50)` | NOT NULL | Office city location |

---

## Problem Statement

Generate a summary of all company departments. Output the department ID, department name, office location, and include a static column labeled `status` containing the text value `'Active'` for all records. Sort by department ID in increasing order.

## Expected Output Columns

| department_id | department_name | location | status |
| :--- | :--- | :--- | :--- |
