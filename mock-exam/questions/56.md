# Question 56: High Value Completed Customers

**Topic Covered**: `HAVING`

## Database Schema Reference

### Table: `customers`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `customer_id` | `INT` | PRIMARY KEY | Unique identifier for customer |
| `customer_name` | `VARCHAR(100)` | NOT NULL | Full customer or corporate name |
| `city` | `VARCHAR(50)` | NOT NULL | Customer city location |
| `country` | `VARCHAR(50)` | NOT NULL | Customer country location |
| `registration_date` | `DATE` | NOT NULL | Account registration date |

### Table: `orders`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `order_id` | `INT` | PRIMARY KEY | Unique identifier for order |
| `customer_id` | `INT` | FOREIGN KEY (`customers.customer_id`) | Customer who placed order |
| `employee_id` | `INT` | FOREIGN KEY (`employees.employee_id`) | Employee who handled order |
| `order_date` | `DATE` | NOT NULL | Date order was placed |
| `status` | `VARCHAR(20)` | NOT NULL | Order status (`Completed`, `Pending`, `Cancelled`) |
| `total_amount` | `DECIMAL(10, 2)` | NOT NULL | Total monetary order value |

---

## Problem Statement

Identify VIP customers who have spent a substantial amount on completed purchases. Combine customer profiles with their order history, group by customer ID and customer name, and find customers whose completed order total reaches or exceeds $3,000.00. Display customer ID, customer name, and total completed spend as `total_completed_spend`, sorted from highest spender to lowest.

## Expected Output Columns

| customer_id | customer_name | total_completed_spend |
| :--- | :--- | :--- |
