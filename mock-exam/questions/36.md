# Question 36: Customer Distribution by Country & City

**Topic Covered**: `GROUP BY`

## Database Schema Reference

### Table: `customers`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `customer_id` | `INT` | PRIMARY KEY | Unique identifier for customer |
| `customer_name` | `VARCHAR(100)` | NOT NULL | Full customer or corporate name |
| `city` | `VARCHAR(50)` | NOT NULL | Customer city location |
| `country` | `VARCHAR(50)` | NOT NULL | Customer country location |
| `registration_date` | `DATE` | NOT NULL | Account registration date |

---

## Problem Statement

Provide a detailed geographic breakdown of our customer base. Group customers by country and city, showing the country, city, and customer count as `city_customer_count`. Sort alphabetically by country, then by city.

## Expected Output Columns

| country | city | city_customer_count |
| :--- | :--- | :--- |
