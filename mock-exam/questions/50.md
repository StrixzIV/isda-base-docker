# Question 50: High Salary Rep Completed Orders

**Topic Covered**: `JOIN`

## Database Schema Reference

### Table: `orders`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `order_id` | `INT` | PRIMARY KEY | Unique identifier for order |
| `customer_id` | `INT` | FOREIGN KEY (`customers.customer_id`) | Customer who placed order |
| `employee_id` | `INT` | FOREIGN KEY (`employees.employee_id`) | Employee who handled order |
| `order_date` | `DATE` | NOT NULL | Date order was placed |
| `status` | `VARCHAR(20)` | NOT NULL | Order status (`Completed`, `Pending`, `Cancelled`) |
| `total_amount` | `DECIMAL(10, 2)` | NOT NULL | Total monetary order value |

### Table: `employees`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `employee_id` | `INT` | PRIMARY KEY | Unique identifier for employee |
| `first_name` | `VARCHAR(50)` | NOT NULL | Employee given name |
| `last_name` | `VARCHAR(50)` | NOT NULL | Employee family name |
| `department_id` | `INT` | FOREIGN KEY (`departments.department_id`) | Assigned department ID |
| `salary` | `DECIMAL(10, 2)` | NOT NULL | Annual salary amount |
| `hire_date` | `DATE` | NOT NULL | Date employee was hired |
| `job_title` | `VARCHAR(50)` | NOT NULL | Official job title |

---

## Problem Statement

Identify orders handled by high-earning sales representatives. Retrieve the order ID, representative's first name, representative's salary, and order total amount for completed orders handled by employees earning over $70,000.00 per year. Sort by order total amount from highest to lowest.

## Expected Output Columns

| order_id | first_name | salary | total_amount |
| :--- | :--- | :--- | :--- |
