# Question 101: Employees Hired After Average Hire Date

**Topic Covered**: `SUBQUERY`

## Database Schema Reference

### Table: `employees`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `employee_id` | `INT` | PRIMARY KEY | Unique identifier for employee |
| `first_name` | `VARCHAR(50)` | NOT NULL | Employee given name |
| `last_name` | `VARCHAR(50)` | NOT NULL | Employee family name |
| `department_id` | `INT` | FOREIGN KEY (`departments.department_id`) | Assigned department ID |
| `salary` | `DECIMAL(10, 2)` | NOT NULL | Annual salary amount |
| `hire_date` | `DATE` | NOT NULL | Date employee was hired |
| `job_title` | `VARCHAR(50)` | NOT NULL | Official job title |

---

## Problem Statement

Identify employees hired more recently than the overall company average hire date. Retrieve employee ID, first name, last name, and hire date for employees hired after the average hire date of all staff. Sort chronologically by hire date.

## Expected Output Columns

| employee_id | first_name | last_name | hire_date |
| :--- | :--- | :--- | :--- |
