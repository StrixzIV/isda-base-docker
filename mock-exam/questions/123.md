# Question 123: Parties with High Average Years Served (Textbook Ex 11.12)

**Topic Covered**: `HAVING`

## Database Schema Reference

### Table: `president`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | PRIMARY KEY | President full name |
| `birth_yr` | `INT` | NOT NULL | Birth year |
| `yrs_serv` | `INT` | NOT NULL | Total years served in office |
| `death_age` | `INT` | NULLABLE | Age at death (NULL if living) |
| `party` | `VARCHAR(30)` | NOT NULL | Political party |
| `state_born` | `VARCHAR(30)` | NOT NULL | State of birth |

---

## Problem Statement

Group presidents by party and filter for political parties whose presidents served an average of 5 or more years in office. Display party name as `party` and average years served as `avg_yrs_serv`, sorted by avg_yrs_serv descending.

## Expected Output Columns

| party | avg_yrs_serv |
| :--- | :--- |
