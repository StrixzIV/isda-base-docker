# Question 118: Presidential Marriage Details Join (Textbook Ex 10.01)

**Topic Covered**: `JOIN`

## Database Schema Reference

### Table: `president`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | PRIMARY KEY | President full name |
| `birth_yr` | `INT` | NOT NULL | Birth year |
| `yrs_serv` | `INT` | NOT NULL | Total years served in office |
| `death_age` | `INT` | NULLABLE | Age at death (NULL if living) |
| `party` | `VARCHAR(30)` | NOT NULL | Political party |
| `state_born` | `VARCHAR(30)` | NOT NULL | State of birth |

### Table: `pres_marriage`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | NOT NULL | President full name |
| `spouse_name` | `VARCHAR(50)` | NOT NULL | Spouse full name |
| `pr_age` | `INT` | NOT NULL | President age at marriage |
| `sp_age` | `INT` | NOT NULL | Spouse age at marriage |
| `nr_children` | `INT` | NOT NULL | Number of children |

---

## Problem Statement

Combine president profiles with their marriage records. Display president name (`pres_name`), president age at marriage (`pr_age`), spouse name (`spouse_name`), and spouse age (`sp_age`). Sort by pres_name ascending, then by spouse_name ascending.

## Expected Output Columns

| pres_name | pr_age | spouse_name | sp_age |
| :--- | :--- | :--- | :--- |
