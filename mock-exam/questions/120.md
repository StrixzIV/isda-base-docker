# Question 120: Administration Inauguration Details with State (Textbook Ex 10.05)

**Topic Covered**: `JOIN`

## Database Schema Reference

### Table: `administration`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `admin_nr` | `INT` | PRIMARY KEY | Administration sequence number |
| `pres_name` | `VARCHAR(50)` | NOT NULL | President full name |
| `year_inaug` | `INT` | NOT NULL | Year of inauguration |

### Table: `president`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | PRIMARY KEY | President full name |
| `birth_yr` | `INT` | NOT NULL | Birth year |
| `yrs_serv` | `INT` | NOT NULL | Total years served in office |
| `death_age` | `INT` | NULLABLE | Age at death (NULL if living) |
| `party` | `VARCHAR(30)` | NOT NULL | Political party |
| `state_born` | `VARCHAR(30)` | NOT NULL | State of birth |

---

## Problem Statement

Link presidential inaugurations with the president's birth state. Display administration number (`admin_nr`), president name (`pres_name`), inauguration year (`year_inaug`), and state born (`state_born`). Sort by admin_nr ascending.

## Expected Output Columns

| admin_nr | pres_name | year_inaug | state_born |
| :--- | :--- | :--- | :--- |
