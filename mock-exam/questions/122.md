# Question 122: Presidents with Multiple Marriages (Textbook Ex 11.09)

**Topic Covered**: `HAVING`

## Database Schema Reference

### Table: `pres_marriage`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | NOT NULL | President full name |
| `spouse_name` | `VARCHAR(50)` | NOT NULL | Spouse full name |
| `pr_age` | `INT` | NOT NULL | President age at marriage |
| `sp_age` | `INT` | NOT NULL | Spouse age at marriage |
| `nr_children` | `INT` | NOT NULL | Number of children |

---

## Problem Statement

Identify presidents who were married more than once. Group marriage records by president name and filter for presidents with 2 or more recorded marriages. Display president name as `pres_name` and marriage count as `marriage_count`, sorted by marriage_count descending, then by pres_name ascending.

## Expected Output Columns

| pres_name | marriage_count |
| :--- | :--- |
