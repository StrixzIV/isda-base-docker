# Question 121: States Providing Multiple Presidents (Textbook Ex 11.07)

**Topic Covered**: `HAVING`

## Database Schema Reference

### Table: `president`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | PRIMARY KEY | President full name |
| `birth_yr` | `INT` | NOT NULL | Birth year |
| `yrs_serv` | `INT` | NOT NULL | Total years served in office |
| `death_age` | `INT` | NULLABLE | Age at death (NULL if living) |
| `party` | `VARCHAR(30)` | NOT NULL | Political party |
| `state_born` | `VARCHAR(30)` | NOT NULL | State of birth |

---

## Problem Statement

Identify states that have provided 3 or more U.S. presidents. Group presidents by birth state and filter for states where the count of presidents is 3 or more. Display state name as `state_born` and president count as `pres_count`, sorted by pres_count descending, then by state_born ascending.

## Expected Output Columns

| state_born | pres_count |
| :--- | :--- |
