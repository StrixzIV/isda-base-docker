# Question 55: High Revenue Order Statuses

**Topic Covered**: `HAVING`

## Database Schema Reference

### Table: `orders`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `order_id` | `INT` | PRIMARY KEY | Unique identifier for order |
| `customer_id` | `INT` | FOREIGN KEY (`customers.customer_id`) | Customer who placed order |
| `employee_id` | `INT` | FOREIGN KEY (`employees.employee_id`) | Employee who handled order |
| `order_date` | `DATE` | NOT NULL | Date order was placed |
| `status` | `VARCHAR(20)` | NOT NULL | Order status (`Completed`, `Pending`, `Cancelled`) |
| `total_amount` | `DECIMAL(10, 2)` | NOT NULL | Total monetary order value |

---

## Problem Statement

Identify order statuses that account for significant revenue. Group orders by status and filter for statuses with cumulative revenue exceeding $5,000.00. Display the status name and total revenue as `status_revenue`, sorted by revenue descending.

## Expected Output Columns

| status | status_revenue |
| :--- | :--- |
