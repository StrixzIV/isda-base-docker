# Question 44: Order Items Order Context

**Topic Covered**: `JOIN`

## Database Schema Reference

### Table: `order_items`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `item_id` | `INT` | PRIMARY KEY | Unique identifier for item record |
| `order_id` | `INT` | FOREIGN KEY (`orders.order_id`) | Associated order ID |
| `product_name` | `VARCHAR(100)` | NOT NULL | Name of product |
| `category` | `VARCHAR(50)` | NOT NULL | Product category (`Hardware`, `Software`, `Services`) |
| `unit_price` | `DECIMAL(10, 2)` | NOT NULL | Price per single unit |
| `quantity` | `INT` | NOT NULL | Quantity ordered |

### Table: `orders`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `order_id` | `INT` | PRIMARY KEY | Unique identifier for order |
| `customer_id` | `INT` | FOREIGN KEY (`customers.customer_id`) | Customer who placed order |
| `employee_id` | `INT` | FOREIGN KEY (`employees.employee_id`) | Employee who handled order |
| `order_date` | `DATE` | NOT NULL | Date order was placed |
| `status` | `VARCHAR(20)` | NOT NULL | Order status (`Completed`, `Pending`, `Cancelled`) |
| `total_amount` | `DECIMAL(10, 2)` | NOT NULL | Total monetary order value |

---

## Problem Statement

Connect individual product line items with their parent order status. Display the item ID, product name, order date, and order status for all order items. Sort by item ID in ascending order.

## Expected Output Columns

| item_id | product_name | order_date | status |
| :--- | :--- | :--- | :--- |
