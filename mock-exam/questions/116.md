# Question 116: Years Served & Headcount Summary per Party (Textbook Ex 9.03)

**Topic Covered**: `GROUP BY`

## Database Schema Reference

### Table: `president`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | PRIMARY KEY | President full name |
| `birth_yr` | `INT` | NOT NULL | Birth year |
| `yrs_serv` | `INT` | NOT NULL | Total years served in office |
| `death_age` | `INT` | NULLABLE | Age at death (NULL if living) |
| `party` | `VARCHAR(30)` | NOT NULL | Political party |
| `state_born` | `VARCHAR(30)` | NOT NULL | State of birth |

---

## Problem Statement

For each political party, calculate the total number of years served as `total_yrs_serv`, the total number of presidents as `pres_count`, and average years served per president as `avg_yrs_serv`. Sort by total_yrs_serv descending.

## Expected Output Columns

| party | total_yrs_serv | pres_count | avg_yrs_serv |
| :--- | :--- | :--- | :--- |
