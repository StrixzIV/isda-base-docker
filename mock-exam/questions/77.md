# Question 77: Line Item Total Value Range

**Topic Covered**: `WHERE`

## Database Schema Reference

### Table: `order_items`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `item_id` | `INT` | PRIMARY KEY | Unique identifier for item record |
| `order_id` | `INT` | FOREIGN KEY (`orders.order_id`) | Associated order ID |
| `product_name` | `VARCHAR(100)` | NOT NULL | Name of product |
| `category` | `VARCHAR(50)` | NOT NULL | Product category (`Hardware`, `Software`, `Services`) |
| `unit_price` | `DECIMAL(10, 2)` | NOT NULL | Price per single unit |
| `quantity` | `INT` | NOT NULL | Quantity ordered |

---

## Problem Statement

Find order line items where the total line item value (unit price multiplied by quantity) is between $500.00 and $2,000.00 (inclusive). Display item ID, product name, unit price, quantity, and line total labeled as `line_total`. Sort by line total from highest to lowest.

## Expected Output Columns

| item_id | product_name | unit_price | quantity | line_total |
| :--- | :--- | :--- | :--- | :--- |
