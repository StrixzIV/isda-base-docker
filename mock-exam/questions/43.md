# Question 43: All Departments & Assigned Employees

**Topic Covered**: `JOIN`

## Database Schema Reference

### Table: `departments`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `department_id` | `INT` | PRIMARY KEY | Unique identifier for department |
| `department_name` | `VARCHAR(50)` | NOT NULL | Department name (e.g. Sales, Engineering) |
| `location` | `VARCHAR(50)` | NOT NULL | Office city location |

### Table: `employees`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `employee_id` | `INT` | PRIMARY KEY | Unique identifier for employee |
| `first_name` | `VARCHAR(50)` | NOT NULL | Employee given name |
| `last_name` | `VARCHAR(50)` | NOT NULL | Employee family name |
| `department_id` | `INT` | FOREIGN KEY (`departments.department_id`) | Assigned department ID |
| `salary` | `DECIMAL(10, 2)` | NOT NULL | Annual salary amount |
| `hire_date` | `DATE` | NOT NULL | Date employee was hired |
| `job_title` | `VARCHAR(50)` | NOT NULL | Official job title |

---

## Problem Statement

Generate a complete audit of all departments and any staff members assigned to them. Include all departments regardless of whether they currently have employees assigned. Display department ID, department name, and employee first name (showing NULL for unassigned departments). Sort by department ID ascending, then by employee first name ascending.

## Expected Output Columns

| department_id | department_name | first_name |
| :--- | :--- | :--- |
