# Question 125: Presidents Born in Shared Birth Years (Textbook Ex 12.01a)

**Topic Covered**: `SUBQUERY`

## Database Schema Reference

### Table: `president`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | PRIMARY KEY | President full name |
| `birth_yr` | `INT` | NOT NULL | Birth year |
| `yrs_serv` | `INT` | NOT NULL | Total years served in office |
| `death_age` | `INT` | NULLABLE | Age at death (NULL if living) |
| `party` | `VARCHAR(30)` | NOT NULL | Political party |
| `state_born` | `VARCHAR(30)` | NOT NULL | State of birth |

---

## Problem Statement

For each president who was born in a calendar year in which at least one other president was born, list his name and birth year. Retrieve pres_name and birth_yr for presidents whose birth_yr is in the subquery of birth years having COUNT(*) > 1. Sort by birth_yr ascending, then by pres_name ascending.

## Expected Output Columns

| pres_name | birth_yr |
| :--- | :--- |
