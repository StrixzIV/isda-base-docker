# Question 110: Republican Presidents Born in Texas (Textbook Ex 6.05)

**Topic Covered**: `WHERE`

## Database Schema Reference

### Table: `recent_presidents`

| Column Name | Data Type | Constraints | Description |
| :--- | :--- | :--- | :--- |
| `pres_name` | `VARCHAR(50)` | PRIMARY KEY | President full name |
| `birth_yr` | `INT` | NOT NULL | Birth year |
| `yrs_serv` | `INT` | NOT NULL | Total years served in office |
| `death_age` | `INT` | NULLABLE | Age at death (NULL if living) |
| `party` | `VARCHAR(30)` | NOT NULL | Political party |
| `state_born` | `VARCHAR(30)` | NOT NULL | State of birth |

---

## Problem Statement

List all facts available in the recent presidents table for all presidents who are members of the Republican party and were born in Texas. Display pres_name, birth_yr, yrs_serv, death_age, party, and state_born. Sort by pres_name ascending.

## Expected Output Columns

| pres_name | birth_yr | yrs_serv | death_age | party | state_born |
| :--- | :--- | :--- | :--- | :--- | :--- |
